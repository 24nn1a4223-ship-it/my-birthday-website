Complete Beginner Website Development Guide

A step-by-step walkthrough of how this website is structured, how to run it locally, test it, and deploy it online for free.

Phase 1: Understanding The Architecture

ðŸ› ï¸ Tools & Technologies Used

This website is built with pure, modern Web Standards (HTML5, CSS3, and JavaScript). Here is why this is the perfect architecture for beginners:

  • Zero Complex Setups: No Node.js, npm, compilers, or server databases required to run or edit!
  • Web Audio API: Synthesizes authentic musical tones (chimes, pops, cheerful birthday melodies) directly in the browser with 0 external sound files.
  • HTML5 Canvas & MediaRecorder API: Allows real-time video composition, Ken Burns transitions, and direct video file recording (`.webm`).
  • Sandboxed Iframe Execution: Runs custom birthday code safely and captures console output in real time.

Phase 3: How to Run It on Your Computer

ðŸ’» Running Locally in 5 Seconds

You can run this website on Windows using any of these simple methods:

  1. Method 1 (Instant): Open your file explorer, navigate to the birthday-surprise-app folder, and double-click index.html. It will open in Google Chrome, Microsoft Edge, or Firefox!
  2. Method 2 (VS Code Live Server): If you use Visual Studio Code, install the free extension "Live Server", right-click index.html, and click "Open with Live Server".
  3. Method 3 (Python command): If you have Python installed, open PowerShell in the folder and type:
    python -m http.server 8000
    Then open your browser to http://localhost:8000.
Phase 4: How to Deploy Online for Free

ðŸŒ Make It Accessible to Anyone via a Web Link

Once you have customized your website, you can host it online completely free so friends and family can visit it from their phones or computers:

Option A: Netlify Drop (Easiest - 60 Seconds, No Git Needed!)

  1. Go to app.netlify.com/drop in your browser.
  2. Sign up for a free account.
  3. Drag and drop your entire birthday-surprise-app folder right onto the screen!
  4. Netlify instantly gives you a live public link (e.g., https://my-birthday-surprise.netlify.app).

Option B: GitHub Pages (Free Permanent Hosting)

  1. Create a free account on GitHub.com.
  2. Create a new repository named birthday-surprise.
  3. Upload all files from your birthday-surprise-app folder.
  4. Go to Settings -> Pages, choose branch main, and click Save.
  5. Your site is live at https://yourusername.github.io/birthday-surprise/!
